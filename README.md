# 時間帯別売上分析ダッシュボード (Hourly Sales Analysis Dashboard)

販売管理システム等から出力された時間帯別実績CSVファイルをブラウザ上で解析し、**08:00〜23:00（固定16時間枠）**で売上・客数・打数・値引率・構成比を表とグラフで可視化するローカルWebアプリケーションです。

---

## 🌟 主な機能・特徴

1. **時間帯別（08:00〜23:00）の固定分析フォーマット**
   - 営業時間が10時〜20時などの店舗でも、08:00〜23:00の統一グリッドで比較・分析可能。
   - 営業時間外の時間帯は「0」ではなく「—（データなし）」として扱い、誤認を防止。

2. **時間帯別分析に最適化した6枚のKPIカード**
   - **売上実績**: 総売上（または平均売上）＆ ピーク時間帯（例: 12:00 ¥7,161,755）
   - **客数実績**: 総客数 ＆ ピーク客数時間帯（例: 19:00 2,273人）
   - **買上打数**: 総打数（例: 135,162 打数） ＆ 買上打数（例: 6.4 打数/人）
   - **客単価 ／ 一品単価**: 客単価（例: ¥2,815） ／ 一品単価（例: ¥442）
   - **値引実績**: 全体値引率（例: 4.66%） ／ 値引総額（¥2,914,601） ／ ピーク値引時間帯（20:00 13.94%）
   - **主要時間帯 売上構成比**: 朝・昼・夜3区分（デフォルト）をはじめ、選択した区分の売上比率および金額
 
3. **売上構成比の自由な時間帯区分カスタマイズ・選択機能**
   - **区分の選択（有効/無効）**: チェックボックスで「朝」と「夜」だけ、「昼」と「夕方」だけなど、分析したい区分のみを自由に選択可能。
   - **時間帯の自由変更**: 各区分の開始時刻・終了時刻（08:00〜23:00）をドロップダウンで柔軟に調整。
   - **区分の追加・削除 & 名称変更**: 区分名の変更や、新しい区分（例: 深夜帯など）の追加・不要な区分の削除が可能。
   - **ワンクリック・プリセット**:
     - `朝・昼・夜3区分 (標準)`（朝 08-10時 ／ 昼 11-16時 ／ 夜 17-23時）
     - `詳細5区分`（朝・昼・午後・夕・夜）
     - `昼・夜2区分`（ランチ 11-14時 ／ ディナー 17-21時）
     - `朝・夜2区分`（朝 08-11時 ／ 夜 18-23時）
     - `初期化`
   - カスタマイズした区分設定は IndexedDB に自動保存され、リロード後もそのまま復元。

4. **インタラクティブな複合グラフ（Chart.js）**
   - 売上・値引金額（棒グラフ） ＋ 客数・打数・値引率（折れ線グラフ）。
   - **売上の縦軸単位は「千円」表示**: 目盛り数値を千円単位（`1,000`, `2,000`, `7,000`など）でスマートにスケーリング表示。
   - 各指標チップをクリックして系列の表示/非表示を自在に切り替え。
   - ホバー時に**累計売上・累計客数・累計打数・値引累計率**がポップアップ表示。
   - テーブルの行にマウスを乗せるとグラフ側の該当時間帯が自動ハイライト。
   - **「グラフをPNG保存」** ボタンで高解像度画像を出力。

5. **2ファイル比較機能（分析 vs 比較）**
   - 前週同曜日や他店舗のCSVを「比較データ」スロットにアップロード可能。
   - グラフ上で実線（分析）と破線・淡色（比較）で直感的に重ね描き。
   - 各KPIカードに対比バッジ（比率%、差額ポイント等）を表示。
   - データテーブルに比較列（比較比、値引率差）を自動追加。

6. **複数ファイルの合算・平均機能**
   - ファイル選択ダイアログやドラッグ＆ドロップで複数CSVファイルを一括読み込み可能。
   - ヘッダーの **「合算」「平均」** ボタンで、複数日の合計または1日あたり時間帯平均をワンクリックで切り替え。

7. **データの自動永続化（IndexedDB）**
   - 読み込んだCSVデータ、集約モード、時間帯区分設定はブラウザ内の IndexedDB に保存され、ページをリロードしても自動的に前回の状態を復元。
   - ヘッダーの「ゴミ箱」アイコンでいつでもデータを全消去・初期化可能。

8. **ダークモード ／ ライトモード切替 & 全画面表示**
   - ヘッダーのアイコンからラグジュアリーなダークテーマと清潔なライトテーマを即座に切り替え。
   - 絵文字を排したビジネス用途向けのクリーンなUI設計。

---

## 🔒 セキュリティ設計

- **完全ローカル動作**: 外部通信（API / fetch）は行わず、すべての計算はブラウザ内で完結。
- **XSSの完全排除**: `innerHTML`, `outerHTML`, `document.write`, `eval`, `new Function` を一切使用せず、安全な DOM API (`textContent`, `createElement`) のみで画面構築。
- **厳格な Content Security Policy (CSP)**: `default-src 'none'; script-src 'self';` によりインラインスクリプトや外部スクリプトの実行を完全遮断。
- **Clickjacking 対策**: フレーム内埋め込み（`iframe`）を検知した場合は自動で描画を拒否。

---

## 🚀 起動方法

ブラウザ（Chrome, Edge等）で `hourly sales.html` を直接ダブルクリックして開くだけで利用できます。
サーバーの立ち上げや事前インストールは不要です。
